# Personalized Scholarship Finder AI

## Overview
An AI-powered scholarship discovery system that matches students
with scholarships based on their academic profile and preferences.

## Features
- Student profile input
- Scholarship matching
- CGPA eligibility checking
- Country matching
- Degree and field matching
- Funding preference
- Deadline information
- Required documents
- Official scholarship links
- Email scholarship digest

## Technologies
- Python
- Streamlit
- Pandas
- Activepieces
- Resend API

## How It Works

Student Profile
      ↓
Scholarship Database
      ↓
Eligibility Filtering
      ↓
Match Scoring
      ↓
Personalized Scholarship Results
      ↓
Email Digest

pip install -r requirements.txt
